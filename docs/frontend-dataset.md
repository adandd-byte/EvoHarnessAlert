## 启动

```bash
python3 -m http.server 8091 --bind 127.0.0.1 --directory app/static
```

访问 `http://127.0.0.1:8091`。这个命令仅启动静态前端，默认展示模拟样本，不连接 MySQL/Redis。真实使用通过 FastAPI 提供同一套静态文件，点击“连接后端”后输入已有账号，访问同源的 `/api/profile` 和管理员接口。静态预览服务不提供这些 API。

新版工作台采用深石墨色导航、浅灰工作区、青绿色操作按钮和 P0-P3 优先级色标。全部图标来自本地 Lucide 0.468.0，不依赖外部 CDN；原有 `/admin.html` 入口保留。

## 工作台操作

- **告警队列**：搜索标题、服务、编号，组合筛选优先级、四类告警及处置状态；点击表头排序，每页 10 条。统计仅覆盖当前加载的数据，不代表全站总量。后台接口目前最多返回最近 200 条告警和事件、100 条轨迹。
- **事件详情**：桌面列表与详情分栏，展开按钮切换宽详情；五个标签组织研判、证据、协作记录、处置记录和原始数据。标题、接手/关闭操作不随详情正文滚动。手机选择告警后进入独立详情，返回时保留筛选与分页。
- **证据**：点击证据行展开摘要、时间窗口、来源和引用编号。模拟证据来自冻结夹具，协作步骤明确标为“预期流程”；后端没有工具快照时显示缺失，不合成真实证据、负责人或指标趋势。
- **回放数据集**：独立查看 100 条样本，可按变体筛选、查看预期结果与人工审核状态、载入模拟工作台、下载单例或全部 JSON。切换视图不清除后端认证。
- **接入与处置**：提交前显示目标为本页模拟环境或后端。关闭须确认并填写备注。未关联 Incident（事件）时禁用处置并说明原因；样本详情只读，载入工作台后可模拟操作。
- **后端连接**：仅在完整认证及初始数据加载成功后切入后端；401、403、500、断连均明确报错，不能伪装成模拟成功。模拟模式的接手、备注和告警接入不请求后台 API。

模拟处置、认证信息均只保留在本页内存，刷新后清除。后端操作调用现有 Webhook、Incident 和 Notes 接口。当前没有新增 API，也没有接入 SSE 对话、群机器人或生产取证/自动修复。

## 数据来源与数量

文件：`app/static/fixtures/alert-replay-v1.json`。生成命令：`python3 scripts/build_replay_dataset.py`。

按飞书文档第 19 章的 20 个场景逐项编写，覆盖支付 5xx、数据库复制、跨地域订单、异常进程、Kafka ISR、发布启动失败、Redis 内存、P99 延迟、消费延迟、inode、CPU、证书、连接池、网络、定时任务、404、测试 Pod、采集器、配置和供应商 API。每个场景包含五个变体，共 100 条：

| 变体 | 冻结返回与预期 |
| --- | --- |
| normal | 已有观测，但根因证据不足，继续补证 |
| timeout | 首个工具超时，失败项不可成为事实引用 |
| conflict | 独立观测互相矛盾，保留冲突并要求核验 |
| tenant_denied | 无服务权限；返回拒绝，不泄露证据内容 |
| approval | 提出处置动作，预期等待人工审批，不执行写操作 |

每个优先级 25 条。类型依据场景语义划分，四类型并非平均分配。每条包含中文原文、标准 Webhook 负载、权限范围、版本、工具请求/返回快照、Evidence ID、预期 Task Plan、事实/假设/缺口、最终状态、禁止动作和恢复验证要求。

**这些是合成样本，不是真实生产事故或人工确认金标。** 工具结果中的辅助快照目前是最小摘要夹具，未包含完整日志栈、代码仓库、ES 返回和指标时间序列。它们用于界面、路由和契约回归；后续需由业务专家替换/补充取证内容、确认因果标签，才能用于真实根因能力和 Skill 效果评测。`fixture://` 表示本地样本引用，不能当作外部真实证据链接。

## 验证边界

`tests/test_replay_dataset.py` 校验 100 条输入通过当前 DTO，实际 Runtime 规则路由符合期望，版本生成可重复，事实只引用成功快照，权限拒绝没有返回内容。尚未实现的证据执行、权限门禁和人工审批没有被模拟成已通过端到端验收。

```bash
python3 -m pytest -q tests/test_replay_dataset.py
python3 scripts/check_frontend.py http://127.0.0.1:8091
```

第二条需要单独安装 Playwright 及 Chromium。可通过 `CHROMIUM_EXECUTABLE` 指定已有 Chromium。脚本拦截全部 `/api/**` 请求，不发真实通知、不向真实后端投递告警。覆盖组合筛选、排序、分页、回放、导出、模拟隔离、后端成功路径、401/403/500、断连重试、空数据、提交失败、旧备注响应隔离，以及标题/备注/证据的 HTML 注入防护。结果写入 `target/ui/result.json`，截图写入 `target/ui/`。

原有 `app/rag_eval/alert_eval_cases_zh.json` 保持独立，属于检索样例集；新回放集侧重告警流程与工具快照，不混用两者的指标。
